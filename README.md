# Tesis ZMVM: PM, clima y salud

Repositorio con códigos y materiales utilizados en la tesis "Cambio Climático y Contaminación Atmosférica: Efectos en la Salud Pública de la Zona Metropolitana del Valle de México

## Contenido

- Procesamiento de datos de PM10 y PM2.5
- Cálculo de FAP
- Análisis de extremos térmicos
- Visualizaciones y figuras
- Bases procesadas

## Reproducibilidad

Scripts desarrollados en Python.
